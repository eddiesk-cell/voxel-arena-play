# Voxel Arena play-test build

This repository holds only the built web game (static files) for play-testing. No source code.

- Play: https://eddiesk-cell.github.io/voxel-arena-play/
- Install on a phone + tester guide (Lao and English): https://eddiesk-cell.github.io/voxel-arena-play/install.html
- Android app (APK): see the `playtest-3` release.

Current build: play-test 7 (version 0.6.0): controls recalibrated on the owner's phone - the move stick now starts and draws wherever your left thumb lands, the attack and skill buttons sit closer to the corner, and the item row is one small row at the bottom centre. New map Gilded Ford (diagonal river, three lanes, four jungle quarters, two river pits). Hiding bushes where the gold and exp lanes meet the river on every three-lane map. Hero lock-on and focus portraits, monster HP numbers, damage numbers that merge and re-pop, a touch-point skill pad (Settings > Controls), ranked crests and a "How ranked works" page, balance round 4, retuned battle spells and standard emblem talents, and reporting a player in casual online rooms. It plays vs AI only (also offline after the first load). Online play is coming soon.

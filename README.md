# Voxel Arena play-test build

This repository holds only the built web game (static files) for play-testing. No source code.

- Play: https://eddiesk-cell.github.io/voxel-arena-play/
- Install on a phone + tester guide (Lao and English): https://eddiesk-cell.github.io/voxel-arena-play/install.html
- Android app (APK): see the `playtest-3` release.

Current build: play-test 8 (version 0.7.0): a hero shop. You start by choosing one free hero from five, then earn battle points from matches to buy the rest; eight heroes are free for everyone each week and change every Monday. Any hero, owned or not, can be tried in an offline one-on-one against an AI that fights back, so you can learn it before buying. Every skill now has a looping clip of it actually being cast, with a plain-words explanation, one tap from the shop or hero select. Controls: the attack button registers a press over the area your thumb aims at again, and the move stick only starts on the left half so it no longer steals a near miss on Recall or Mend. It plays vs AI only (also offline after the first load). Online play is coming soon.

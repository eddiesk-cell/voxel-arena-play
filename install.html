Install on iPhone

  1. Open this page in Safari (not Chrome).
  2. Tap Play now above so the game opens.
  3. Tap the Share button (the square with the arrow pointing up).
  4. Scroll down and tap Add to Home Screen, then Add.
  5. Start Voxel Arena from its new icon: it opens full screen. Turn the phone sideways.

Install on Android

  1. Open this page in Chrome and tap Play now.
  2. Tap the ⋮ menu (top right), then Install app (or Add to Home screen).
  3. Or tap the Install message the game shows at the bottom.

Or get the Android app (APK):

Download Android app

After the download, open the file and tap Install. If Android asks, allow "Install unknown apps" for your browser once. This is a test build, so Play Protect may ask you to confirm.
